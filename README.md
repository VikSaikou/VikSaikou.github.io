# Access Decisions Lab

A practical Microsoft Entra ID lab focused on access decisions, identity lifecycle, privileged access, first sign-in controls, and audit-ready Service Desk evidence.

This project uses a fictional company, **AustraKey Lab**, to model common IAM problems in a small growing environment: informal access requests, unclear approval ownership, weak onboarding evidence, privileged access uncertainty, and poor handoff quality between business, IT support, and audit needs.

The goal of this lab is not to show random portal screenshots.  
The goal is to show how access decisions are requested, approved, implemented, validated, and documented.

This lab shows how a lightweight IAM process can improve traceability without introducing heavy bureaucracy.
