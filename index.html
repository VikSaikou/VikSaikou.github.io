Portfolio Overview

This portfolio is built around one idea: practical cybersecurity work should be
clear enough to explain, structured enough to review, and documented enough to trust.
The retro Windows XP-inspired interface is intentional: nostalgia gets attention, but structure earns trust.

  • Project areas: GRC, business continuity, small-business security and knowledge management
  • Method: translate business risks and technical realities into practical controls, clear documentation, and reviewable evidence
  • Goal: make cybersecurity easier to understand, operate, review, and improve

ISO/IEC 27001 Control Dependency Map

Public · v1.0

A visual and tabular model showing how key Annex A controls and ISO/IEC 27001 activities depend on one another. A foundation for an emerging taxonomy of security-control relationships.

The project includes an editable dependency model, diagrams, a structured dependency table, and the methodology used to assess relationships between controls.
